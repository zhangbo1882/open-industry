# 东方环宇 (SH603706)

> 东方环宇是一家集城市基础设施和公用事业投资、建设、运营和管理为一体的公用事业服务商，主要从事城镇燃气的输配与运营业务（包括天然气终端销售和服务、天然气用户设施设备安装业务）以及城市集中供热业务。2025年营收13.31亿元（-7.77%），归母净利润2.16亿元（+9.43%），ROE 13.04%。「来源：2025年年报」

## 公司概况

- **全称**：新疆东方环宇燃气股份有限公司
- **股票代码**：SH603706
- **所属行业**：公用事业 / 燃气 / 燃气
- **产业链位置**：中游（城镇燃气输配与集中供热服务运营商）
- **经营区域**：城市燃气供应经营区域为昌吉市行政区域范围（包括主城区、各乡镇、园区）；城市集中供热供应经营区域为智慧能源所供热区域范围之外的伊宁市行政区域范围
- **业务定位**：城市燃气供应 + 城市集中供热的公用事业服务商

> 公司业务涵盖天然气终端销售、天然气设施设备安装、城市集中供热三大板块。2025年燃气相关业务（天然气销售 + 设施安装）合计营收约6.75亿元，供热业务营收约6.31亿元。「来源：2025年年报」

## 财务数据（2025年年度报告）

| 指标 | 2025年 | 同比变动 |
|------|--------|----------|
| 营业收入 | 13.31亿元 | -7.77% |
| 归母净利润 | 2.16亿元 | +9.43% |
| 加权平均ROE | 13.04% | +0.85个百分点 |
| 主营业务毛利率 | 28.45% | +4.36个百分点 |
| 经营活动现金流净额 | 2.70亿元 | -28.42% |

**简要解读**：

- 营收同比下降7.77%，主因天然气销售业务（-14.02%）和设施设备安装业务（-22.91%）营收下滑，而供热业务小幅增长（+3.27%）。
- 归母净利润逆势增长9.43%，得益于主营业务毛利率提升4.36个百分点（营业成本降幅-13.58%大于营收降幅-8.31%），降本增效成效明显。
- 经营现金流净额下降28.42%，但绝对值仍为正值（2.70亿），覆盖净利润。
- ROE 13.04%，较上年12.19%提升0.85个百分点，盈利能力改善。

## 产业链位置

东方环宇处于公用事业产业链**中游**，是连接上游能源供应商与下游终端用户的燃气输配及供热服务运营商。

### 上游
- **天然气供应商**：中石油销售新疆分公司、中石化、庆华能源为公司的三大主力气源供应商，天然气购销合同「一年一签」
- **热源**：伊宁供热热源来自热电联产企业及自有燃煤锅炉（应急热源保障），与上游热电联产企业维持长期良好合作关系
- **上游产业链接**：[[石油天然气]] · [[热电联产]]

### 中游（公司位置）
- 城镇燃气管网近3,000公里，覆盖昌吉市建成区及部分乡镇、各园区
- 伊宁供热系伊宁市规模最大、最主要的热力供应企业
- 业务模式：管网输配 + 终端销售 + 安装服务 + 集中供热

### 下游
- 居民用户、商业用户、工业用户（天然气终端消费）
- 伊宁市主城区核心商圈和大型生活社区居民（集中供热）
- **下游产业链接**：居民消费 · 工业用气

## 核心竞争力

1. **区域市场占有率及先发优势**：天然气管网近3,000公里，覆盖昌吉市建成区及部分乡镇、各园区；伊宁供热系伊宁市规模最大的热力供应企业，占据主城区核心商圈和大型生活社区，用热负荷稳定、市场地位稳固。「来源：2025年年报」

2. **气源多元化和多渠道供应保障**：周边有新疆油田、吐哈油田等大型油气田，与中石油、中石化、庆华能源建立了稳定合作关系，打通了资源跨省串换的模式和渠道。「来源：2025年年报」

3. **信息化管理优势**：深度融合SCADA系统、GIS管网及智能感知网络，构建"智能感知-分析-响应-优化"闭环体系，实现管网运行实时监控和智能调度。「来源：2025年年报」

4. **安全生产优势**：获得新疆维吾尔自治区《安全标准化二级企业》达标认证，建立风险分级管控与隐患排查治理双重预防机制。「来源：2025年年报」

5. **运营管理经验**：拥有25年行业经验，培养了一批业务素质优秀、对公司高度忠诚的管理团队和专业技术人才队伍。「来源：2025年年报」

6. **行业中长期机遇**：双碳背景下天然气作为最现实、可靠、清洁的绿色低碳能源，行业具有重大中长期发展机遇。「来源：2025年年报」

## 风险因素

| 风险项 | 说明 |
|--------|------|
| 产业政策风险 | 天然气行业对政府政策依赖性较强，政府监管政策和监管力度的变化会给企业经营模式和收益带来风险。「来源：2025年年报」 |
| 定价机制风险 | 上游气价变动时终端售价不会自动联动，下游实行价格联动存在时差，可能导致燃气企业资金周转困难、利润率降低。「来源：2025年年报」 |
| 市场区域集中风险 | 公司经营区域主要集中于新疆昌吉市及伊宁市，与两地的城市化进程、区域经济发展速度、居民收入水平密切相关。「来源：2025年年报」 |
| 气源依赖风险 | 上游气源供应商主要为中石油下属单位，天然气购销合同「一年一签」，若上游因政策或季节性因素不能满足公司用气需求，可能对公司气源供应造成不利影响。「来源：2025年年报」 |
| 安全生产风险 | 天然气属于易燃、易爆气体，存在因人为操作失误、用户使用不当或燃气用具质量问题引发安全事故的可能。「来源：2025年年报」 |
