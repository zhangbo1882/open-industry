# 东诚药业 (SZ002675)

> 核药（放射性核素药物）全产业链龙头，31个核药生产中心覆盖国内93.5%人口；肝素API出口行业领先；蓝纳成是国内进入临床阶段放射性诊疗一体化药物数量排名第一的公司。2025年营收27.41亿（-4.46%），归母净利润1.96亿（+6.42%）。「来源：2025年年报」

---

## 公司概况

- **全称**：烟台东诚药业集团股份有限公司
- **股票代码**：SZ002675
- **所属行业**：医药生物 / 医药 / 化学制药
- **产业链位置**：中游（药品制造环节）
- **一句话定位**：以核药业务与化药业务（原料药+制剂）为核心双轮驱动的综合型医药制造企业，全面覆盖放射性核素药物全链条，同时经营抗凝血肝素类原料药及下游制剂。

> 公司以核医药业务、化药业务（含原料药业务与制剂业务）为核心经营发展基石，全面覆盖放射性核素药物全链条产业，同时开展抗凝血肝素类原料药的生产销售，并积极向其下游制剂领域延伸扩展。「来源：2025年年报」

## 产业链位置

### 上游 — 原材料与核心要素
- **医用同位素**：放射性核素药物的核心原料，依赖反应堆/加速器生产，国内长期依赖进口。公司通过「一堆两器」（九江天红反应堆+40MeV花瓣加速器+30MeV质子回旋加速器）布局自主供应。
- **肝素粗品**：肝素原料药的核心原料，从生猪小肠黏膜提取，受生猪出栏量及全球供需影响，价格波动较大。
- **化学中间体**：制剂产品所需的API及辅料。

### 中游 — 药品制造（公司所在位置）
东诚药业处于药品制造环节，横跨三大业务板块：
- **核药制造**：放射性诊断药物（显像剂、正电子示踪剂）、放射性治疗药物（籽源、诊疗一体化药物），依托31个核药生产中心全国配送。
- **原料药制造**：肝素钠API、硫酸软骨素，出口全球40多个国家和地区。
- **制剂制造**：冻干粉针剂（年产7000万支），覆盖抗凝、心血管、抗肿瘤等治疗领域。

### 下游 — 终端应用
- 医院核医学科、影像中心（PET-CT/SPECT）、放疗科
- 肝素制剂厂商（国内外药企）
- 药品流通企业、零售药房

> 上游同位素/原料供应 ← **东诚药业（中游制造）** → 下游医疗机构/药企「来源：2025年年报」

## 核心竞争力

- **核素供应平台**：构建「一堆两器」放射性医用同位素开发生产平台——与国电投/江西核电合作的九江天红医用同位素专用反应堆项目、与中国工程物理研究院合作的40MeV花瓣加速器、与德国Eckert & Ziegler合作的30MeV质子回旋加速器，保障医用同位素可持续自主供应。「来源：2025年年报」
- **药物孵化平台**：蓝纳成是国内领先的放射性诊疗一体化创新核药研发平台，覆盖PSMA、FAP及αvβ3等核心靶点的13款候选药物，进入临床阶段放射性诊疗一体化药物数量排名国内第一。「来源：2025年年报」
- **CRDMO服务平台**：以米度生物为核心，提供从早筛化合物到上市注册的一站式核药CRDMO服务，已成功标记超过600种化合物，助力30多个核药产品获得临床试验批件。「来源：2025年年报」
- **生产配送平台**：31个在营核药生产中心（7个单光子+22个正电子+2个其他运营中心），基本覆盖国内93.5%人口的核医学需求。「来源：2025年年报」
- **垂直一体化肝素产业链**：肝素API出口、硫酸软骨素生产居于行业领先地位，拥有从原料到制剂的完整产业链，销售网络遍布全球40多个国家和地区。「来源：2025年年报」
- **制剂业务平台**：年产7000万支冻干粉针剂生产线，产品覆盖抗凝、心血管、抗肿瘤、泌尿、骨科及抗感染等多个治疗领域，注射用氢化可的松琥珀酸钠年销量突破1000万支。「来源：2025年年报」

## 风险因素

| 风险类别 | 具体描述 |
|----------|---------|
| 原材料价格波动 | 肝素钠原料药主要原材料为肝素粗品，生猪出栏量波动导致采购价格波动，影响原料药板块盈利。 |
| 折旧增加导致业绩下滑 | 近年固定资产投资较高，新增折旧较大，新建项目初期收入较少可能无法弥补当期折旧。 |
| 环保安全风险 | 公司属于医药制造行业，生产经营中产生污染物，环保法规日益严格将增加环保支出。 |
| 药品研发不达预期 | 药品研发周期长、资金投入大、审批环节多，存在研发不达预期及注册周期延长的风险。 |
| 人才缺乏风险 | 公司规模扩张和业务拓展中，管理人才和专业人才储备与公司发展需求存在匹配差距。 |
| 规模扩张管理风险 | 多次外延式并购和募集资金投资项目实施使资产和业务规模扩大，管理难度加大。 |
| 医药改革政策风险 | 药品审批、质量监管、药品招标、医保控费、集中采购等系列政策带来行业政策变化风险。 |
| 汇率波动风险 | 出口产品收入以美元结算，人民币汇率大幅波动将对经营业绩产生影响。 |

> 以上风险因素均摘自2025年年报管理层讨论章节。

## 员工·专利·R&D

- **员工规模**：报告期末在职员工2,583人（母公司370人+主要子公司2,213人）。其中生产人员827人、销售人员265人、技术人员964人、财务人员95人、行政人员341人、管理人员91人。硕士及以上289人、本科1,179人、专科659人、专科以下456人。「来源：2025年年报」
- **专利情况**：报告未明确披露专利总数。资产负债表中「专利权」账面原值期末余额见年报。蓝纳成拥有「完全自主知识产权的诊断与治疗一体化创新核药研发平台」。公司通过自主研发、专利授权、新药转化、合资合作等方式引进开发产品。「来源：2025年年报」
- **研发投入**：2025年研发投入288,872,210.35元（约2.89亿元），占营业收入比例10.54%，同比下降32.99%。其中资本化金额56,261,573.30元，资本化率19.48%。研发人员456人，占员工总数17.65%。核素药物研发投入占研发总投入81.51%。「来源：2025年年报」
