# 中哲精化 (SZ000953)

> 公司原名「广西河池化工股份有限公司」（河化股份），2025年控股股东由银亿控股变更为中哲集团后更名为中哲精化。主营医药中间体（氯喹侧链/羟基氯喹侧链等）及尿素委托加工。2025年营收1.80亿（-15.05%），归母净利0.07亿（-91.77%），ROE 4.38%。 来源：2025年年报

## 产业链位置

- **上游**：基础化工原料（氨、甲醇、液碱等）、能源（电力/蒸汽）、医药中间体前端原料 → 供应商集中度极高（前五占82.30%，第一大占58.29%）
- **中游（公司位置）**：医药中间体合成（催化加氢/氨化反应/精馏） + 尿素委托加工
- **下游**：原料药生产企业、制剂药企、农药/化肥经销商 → 客户集中度较高（前五占62.90%）

公司在医药中间体产业链中处于中游制造环节，为下游原料药及制剂企业提供关键中间体（氯喹侧链、羟基氯喹侧链等）。尿素业务为委托第三方加工模式，公司不直接从事尿素生产。

## 核心竞争力

- **催化加氢工艺资质**：南松医药拥有催化加氢工艺稀缺资质，在医药中间体行业中具备准入门槛优势。 来源：2025年年报
- **氨化反应技术**：自主研发的氨化反应工艺可大幅提升反应收率，降低生产成本。 来源：2025年年报
- **高温高真空精馏技术**：精准控制杂质含量，满足高端原料药客户的纯度要求。 来源：2025年年报
- **产品认证与荣誉**：羟基氯喹侧链曾被评为国家火炬计划项目、国家重点新产品、重庆市重点新产品和高新技术产品；氯喹侧链曾被评为重庆市重点新产品和高新技术产品。南松凯博为国家高新技术企业、重庆市「专精特新」企业。 来源：2025年年报
- **客户黏度**：建立了一批长期合作且稳定的高端客户群体，下游客户更换供应商成本及风险较高。 来源：2025年年报
- **装备齐全**：拥有五个生产车间，中试车间有多套300-3000升反应釜，七车间设一般反应区和洁净生产区。 来源：2025年年报
- **管理团队经验**：管理和技术团队拥有平均超过20年的医药化工企业管理经验。 来源：2025年年报

## 风险因素

| 风险类别 | 具体描述 |
|---------|---------|
| 药品带量采购政策风险 | 医疗改革「带量采购」政策导致药品终端价格大幅降低，相关医药中间体面临产品价格下降的风险 |
| 汇率波动风险 | 出口业务收入以外币结算，汇率变化直接影响原材料和商品价格，影响出口产品竞争力 |
| 产品市场需求波动风险 | 氯喹侧链为抗疟疾药磷酸氯喹的关键中间体，疟原虫对磷酸氯喹出现耐药性可能导致订单逐年萎缩 |
| 安全环保风险 | 部分原材料、半成品或产成品易燃易爆、腐蚀性或有毒，环保要求日趋提高将导致环保成本增加 |
| 贸易政策变动风险 | 进口国政策变动、税率调整或贸易摩擦导致关税成本上升，削弱产品价格竞争力 |
| 证券市场风险 | 股票价格受公司经营状况、盈利能力、行业发展、宏观经济、国家政策等多重因素影响 |

> 以上风险均来自2025年年报管理层讨论部分。 来源：2025年年报
