# 东方锆业（SZ002167）2025年年度报告

| 指标 | 数值 |
|------|------|
| 报告期 | 2025年度 |
| 营业收入 | 12.45亿元 |
| 归母净利润 | 0.53亿元 |
| 加权平均ROE | 3.04% |
| 综合毛利率 | 16.84% |
| 经营活动现金流净额 | 3.95亿元 |

## 报告摘要

广东东方锆业科技股份有限公司2025年年度报告。公司主营锆系列制品研发、生产和销售。2025年锆行业整体处于周期性调整阶段，市场需求偏弱叠加行业竞争加剧，营收同比下降19.32%至12.45亿元，归母净利润同比下降70.16%至0.53亿元。但综合毛利率逆势上升6.45个百分点至16.84%。

## 主营结构

- 无机非金属锆产品：占营收89.61%（毛利率15.82%）
- 无机非金属材料产品：占营收6.14%（毛利率26.42%）
- 国内收入占76.41%，国外占23.59%

## 关键关联方

- 龙佰集团为控股股东（持股24.99%）及第一大供应商（采购占比51.85%）
- 参股合肥固宁纪元新能源科技有限公司（固态电池赛道布局）
