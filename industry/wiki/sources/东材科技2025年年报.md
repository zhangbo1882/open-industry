# 东材科技 (SH601208) 2025年年报

| 指标 | 数值 |
|------|------|
| 营业收入 | 51.81亿元 |
| 归母净利润 | 2.85亿元 |
| 加权平均ROE | 5.61% |
| 毛利率（化工新材料） | 15.67% |
| 经营活动现金流净额 | 0.80亿元 |

> 报告期间：2025年1月1日 — 12月31日。东材科技主要从事化工新材料的研发、生产和销售，以新型绝缘材料为根基，重点布局电子材料、光学膜材料、新能源材料、环保阻燃材料等系列产品。2025年营收同比+15.91%，归母净利润同比+57.68%。
