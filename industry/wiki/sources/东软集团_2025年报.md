# 东软集团 (SH600718) 2025年年报

| 指标 | 数值 |
|------|------|
| 报告期 | 2025年度 |
| 营业收入 | 120.38亿（同比+4.14%） |
| 归母净利润 | -3.58亿（同比-668.07%） |
| ROE（加权平均） | -3.88% |
| 毛利率（整体） | 22.11% |
| 经营现金流净额 | 4.51亿（同比-47.24%） |
| 研发投入 | 12.35亿（占营收10.26%，同比+34.07%） |
| 员工总数 | 23,737人 |

> 东软集团是中国第一家上市软件公司，2025年营收微增至120.38亿，但归母净利润由盈转亏（-3.58亿），主要受智能汽车互联毛利率偏低、行业竞争加剧及研发投入大幅增长影响。
